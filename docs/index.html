Limitations

  • Fixtures are synthetic JSON built from the real schema shapes; the harness checks the rules as transcribed from the cited source lines, it does not compile or execute postfiatd (a full build is not feasible on this machine).
  • Publisher-list signatures in the fixtures are synthetic sha256 stand-ins that exercise the verify-then-apply rule, not real ed25519 signatures.
  • Upstream comparison covers AmendmentTable.cpp, ValidatorList.cpp, and SystemParameters.h. The upstream sparse checkout used here does not contain src/xrpld/app/tx or the xrpl include tree, so no upstream diff is claimed for the fee/sequence code.
